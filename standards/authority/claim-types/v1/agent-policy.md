# Agent Policy: Claim Type Authority v1

Agents MUST apply this policy before changing or relying on any artifact:

1. Identify every claim that will affect code, repository state, user-facing
   text, or workflow behavior.
2. Assign one claim type from the standard.
3. Locate the owner surface for that claim type.
4. If the current artifact is not the owner surface, treat it as orientation or
   citation only.
5. If no owner surface exists, create a scoped exception or introduce the proper
   owner artifact before implementing the claim.

Agents MUST report non-claims explicitly when a generated artifact might be
misread as proof.
