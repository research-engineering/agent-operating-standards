# Code of Conduct

This project follows the Contributor Covenant Code of Conduct:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Participants should keep discussion focused on evidence, standards, and
maintainable engineering decisions. Harassment, personal attacks, or attempts to
coerce maintainers are not acceptable.

Instances of unacceptable behavior may be reported through the repository
security or maintainer contact path when one is available.
